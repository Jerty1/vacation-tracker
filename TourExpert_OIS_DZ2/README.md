# ТурЭксперт — экспертная система выбора туристического направления

Учебный прототип по дисциплине «Основы интеллектуальных систем», домашнее задание 2-1.

**Скачать:** [ZIP с исходным кодом, двумя SQLite-базами, тестами и отчётом](./TourExpert_OIS_DZ2_solution.zip).

## Запуск

1. Скачайте ZIP и распакуйте архив.
2. Установите Python 3.10+.
3. В папке `ТурЭксперт` запустите `python app.py` или `Запуск_Windows.bat`.
4. Откройте `http://127.0.0.1:8765` в браузере.

В прототипе: 24 вопроса, 25 туристических направлений, 20 характеристик объектов, автономная база знаний, рабочая база данных, интерактивный топ-5 и полный финальный рейтинг.

Показатели стоимости, длительности перелётов и другие туристические характеристики приведены как условные учебные оценки; не использовать для реальных бронирований.
